# 🛠️ ServiceDesk Plus

Повноцінний веб-додаток для управління заявками на ремонт техніки та IT-підтримку.

## ✨ Функціонал:
- **Клієнти:** Реєстрація, створення заявок з фото та дедлайном, чат з майстром, отримання PDF-талонів та гарантій.
- **Адміністратори:** Панель зі звітами, зміна статусів заявок, чат, внутрішні нотатки, видалення заявок.
- **Постачальники:** Окремий кабінет для перегляду заявок у роботі та коментування.
- **Telegram-бот:** Миттєві сповіщення клієнтам про зміну статусу.

## 🛠️ Технології:
- Python, FastAPI, SQLAlchemy (SQLite), Jinja2, TailwindCSS, WeasyPrint, Telegram Bot API.

## 🚀 Як запустити:
1. Клонуйте репозиторій: `git clone ...`
2. Створіть віртуальне оточення: `python -m venv .venv`
3. Активуйте його: `.venv\Scripts\activate` (Windows)
4. Встановіть залежності: `pip install -r requirements.txt`
5. Створіть файл `.env` (як у `.env.example`) та вкажіть свій `TELEGRAM_BOT_TOKEN`.
6. Запустіть: `python main.py`
